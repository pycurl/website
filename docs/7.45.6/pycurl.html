pycurl Module Functionality¶

pycurl.version¶

This is a string with version information on libcurl, corresponding to curl_version in libcurl.

Example usage:

>>> import pycurl
>>> pycurl.version
'PycURL/7.19.3 libcurl/7.33.0 OpenSSL/0.9.8x zlib/1.2.7'
